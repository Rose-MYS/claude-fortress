    1-Minute Beginner Guide to Working With Your Agent

    1. Install Only the Skill Folder

    Copy only claude-fortress/ to your host's skills folder: Claude Code uses ~/.claude/skills/ (or project .claude/skills/); generic hosts use ~/.agents/skills/.

    2. Copy Prompts — No Commands to Memorize

    Select a route, click Step 1, copy the preparation prompt, and paste it to your Agent. The Agent reports in 3 short parts: Confirmed / Not Checked / Next Step.

    3. Read Tier A / B / C Badges

    Tier A (Green) offline read-only; Tier B (Blue) reversible local writes or neutral probes; Tier C (Red) firewalls, disconnects, cleanup, or touching Claude — Agent must pause for your explicit yes.

    4. Privacy & Self-Verify Rules

    Never commit passwords, tokens, private keys, or personal names/handles. Always self-verify cold boot, warm reboot, and fail-closed blocks on your own machine before attaching a real account.
