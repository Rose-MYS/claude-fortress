    1-Minute Beginner Guide to Working With Your Agent

    1. Install Only the Skill Folder

    Copy only claude-fortress/ to your host's skills folder: Claude Code uses ~/.claude/skills/ (or project .claude/skills/); generic hosts use ~/.agents/skills/.

    2. Copy Prompts — No Commands to Memorize

    Select a route, click Step 1, copy the preparation prompt, and paste it to your Agent. The Agent reports in 3 short parts: Confirmed / Not Checked / Next Step.

    3. Read Tier A / B / C Badges

    Tier A (Green) offline read-only; Tier B (Blue) reversible local writes or neutral probes; Tier C (Red) firewalls, disconnects, cleanup, or touching Claude — Agent must pause for your explicit yes.

    4. Privacy & Self-Verify Rules

    Never commit passwords, tokens, private keys, or personal names/handles. Always self-verify cold boot, warm reboot, and fail-closed blocks on your own machine before attaching a real account.

    📦 Install the claude-fortress Skill

    Pick whichever way suits you and copy-paste. Installing only places files in a skills folder — no script is run.

    Send this to the agent you already use (Claude Code, Codex, Antigravity…) and it will do the install for you.

    Send to your Agentyour OS
    Please install the claude-fortress Skill: if you are Claude Code, clone https://github.com/Rose-MYS/claude-fortress into ~/.claude/skills/claude-fortress (on Windows: %USERPROFILE%\.claude\skills\claude-fortress); if you are another agent, clone it into the skills folder you actually load. Only do the install — do not run any script from the repository. Then tell me the install path and confirm you can see the claude-fortress Skill.

    Run these two commands inside a Claude Code session. Later, /plugin updates or removes it in one step.

    ① Add the marketplaceyour OS
    /plugin marketplace add Rose-MYS/claude-fortress
    ② Install the pluginyour OS
    /plugin install fortress@rose-mys
    The plugin is named fortress; the Skill inside it is claude-fortress. In a terminal, use claude plugin instead of /plugin.

    If you have git, one command installs it into Claude Code's user-level skills folder:

    macOS / Linuxyour OS
    git clone https://github.com/Rose-MYS/claude-fortress.git ~/.claude/skills/claude-fortress
    Windows (PowerShell)your OS
    git clone https://github.com/Rose-MYS/claude-fortress.git "$env:USERPROFILE\.claude\skills\claude-fortress"
    To update later, run git pull in that folder. For other agents use the skills folder they actually load; for one project only, use that project's .claude/skills/.

    ⬇ Download claude-fortress.zip (latest)

    1. Claude on the web / desktop: open Customize → Skills, click “+” → “Create skill” → “Upload a skill” and upload the zip as-is, without unzipping. Code execution and file creation must be on in Settings → Capabilities.
    2. Claude Code / other agents: unzip, then put the whole claude-fortress folder into ~/.claude/skills/ (or your agent's skills folder).
    Getting a 404? No release has been published yet — download the main branch archive instead and rename the folder claude-fortress-main to claude-fortress.
